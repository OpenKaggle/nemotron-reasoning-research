# Data sources and access boundary

This repository intentionally contains no competition records. To reproduce a
permitted workflow, obtain inputs from the official competition after accepting
its rules:

- [NVIDIA Nemotron Model Reasoning Challenge](https://www.kaggle.com/competitions/nvidia-nemotron-model-reasoning-challenge)

Do not copy the downloaded files into this repository. Keep them in an ignored
local directory, record the acquisition date and checksum privately, and use a
local configuration file for paths. Base models, public notebooks, and other
third-party dependencies must be retrieved from their original publisher under
their own terms.

The public tree may contain source code that operates on a locally authorized
input, but it must not contain a row, sample, identifier, answer, prediction,
completion, token trace, or local path from that input.
