## 5. Known Kaggle script-mode pitfalls (already fixed in v6, but document for context)

### 5.1 Mount path convention
- **Dataset_sources** mount: `/kaggle/input/datasets/<owner>/<slug>/`
- **Competition_sources** mount: `/kaggle/input/competitions/<comp-slug>/`
- **Model_sources** mount: `/kaggle/input/models/<owner>/<slug>/<framework>/<variation>/<version>/`
- **Kernel_sources** mount: `/kaggle/usr/lib/notebooks/<owner>/<kernel-slug-with-dashes-replaced-by-underscores>/`
  - Critical: script-mode replaces `-` with `_`. Kienngx notebook code uses dash form; we must use underscore.
- **Sys.path**: kernel_source mount is **not** auto-added to sys.path in script mode. Must explicitly `sys.path.insert(0, NVUTIL)`.

### 5.2 Triton ptxas-blackwell PermissionError
- The kernel_source mount is read-only and binaries lack the executable bit.
- Kienngx's chmod-to-/tmp fix relies on `os.path.exists(src)` returning True for the dash-form path, which it doesn't in script mode.
- **Our fix (v6)**:
  - Force-copy `ptxas-blackwell` to `/tmp` regardless of `os.path.exists`.
  - Set `TRITON_PTXAS_PATH` and `TRITON_PTXAS_BLACKWELL_PATH` env vars.
  - **Most important**: monkey-patch `triton.backends.nvidia.compiler.get_ptxas = lambda arch: _FakePtxas(version="12.0")` so Triton's compile path never subprocess-invokes ptxas.

### 5.3 `kernel-metadata.json` flipping to notebook
- Something in the local toolchain (possibly Cursor IDE's notebook viewer) auto-creates a `.ipynb` and edits metadata to `kernel_type: notebook`. If a stale .ipynb sits in the kernel directory, push silently uses it.
- **Defense**: before every push, verify `kernel-metadata.json` has `kernel_type: "script"` and `code_file` ends in `.py`. Delete any stray `.ipynb`.

### 5.4 `base_model_name_or_path` rewrite
- PEFT's default `save_pretrained` writes the kagglehub local cache path (`/kaggle/input/models/...`) into `adapter_config.json`'s `base_model_name_or_path`.
- Empirically, evaluator sometimes accepts the local path (Kienngx 0.86) and sometimes scores 0.50 (our old runs).
- **Defense**: at end of training script, rewrite to public HF id `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16` if it starts with `/`. Already in our `.py`.

### 5.5 Kaggle status endpoint flicker
- `kaggle kernels status` occasionally reports stale ERROR/COMPLETE during a running kernel.
- **Defense**: if status flips ERROR → RUNNING, trust the latter. Only download outputs and read logs when status has been stable for ≥1 poll cycle AND the running_for_ms is consistent.

A helper at `<redacted-path> (recreate if missing):
```bash
cat > <redacted-path> <<'EOF'
#!/bin/bash
KERNEL="$1"
INTERVAL="${2:-300}"
PREV=""
while true; do
  CUR=$(env -u HTTPS_PROXY -u HTTP_PROXY -u ALL_PROXY -u https_proxy -u http_proxy -u all_proxy .venv/bin/kaggle kernels status "$KERNEL" 2>&1)
  TS=$(date +"%Y-%m-%d %H:%M:%S")
  [ "$CUR" != "$PREV" ] && { echo "[$TS] $CUR"; PREV="$CUR"; }
  if echo "$CUR" | grep -qE "COMPLETE|ERROR|CANCEL"; then
    echo "[$TS] terminal state reached, exiting"; exit 0
  fi
  sleep "$INTERVAL"
done
EOF
chmod +x <redacted-path>
```
