# Nemotron workbench reports (2026-09-28)

This directory preserves first-party research notes, decisions, plans, and
experiment summaries from the local Nemotron workbench. The report bodies are
kept intact except for local absolute paths, which are replaced with portable
placeholders so that a reader can follow the method without exposing a
machine-specific directory layout.

This is a report archive, not a copy of the competition package. It does not
ship official competition rows, holdout/test data, copied third-party
notebooks, model weights, prompt/answer/completion corpora, or row-level trace
exports. Those materials remain represented by source links, provenance notes,
or the separately reviewed sanitized evidence release.

The SHA-256 file covers every report and this README. Reuse the notes with the
repository's citation record and preserve the original dates when quoting an
experiment. External projects and public Kaggle assets mentioned in a note
remain owned by their original publishers.
